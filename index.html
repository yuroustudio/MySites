GoLand 夠練
教練學員共課媒合平台

教練可以把小班課上架、少花力氣招生；學員可以瀏覽、篩選、報名適合自己的課。解決教練湊不到人、學員找課資訊太分散的問題。

  • 負責使用者研究與競品分析：訪談 7 位教練、17 位學員，加上 54 份問卷。
  • 研究推翻了「大家不想跟陌生人上課」的假設：71% 其實不介意，只有 7% 會自己找人。這成為 PRD v4.10 產品定位的依據。
  • 開發學員端「找課程」：縣市→行政區、日期、時段、程度、價格可疊加篩選，條件同步到網址，分享連結就能還原同樣的結果。使用 Supabase、Vercel 部署。

個人專題 / 專案管理師課程 / 2026.08–09

SmartRehab
物理治療預約與居家復健平台

當過個案管理師，看過太多病人痛一好就不回診、回家也不知道該做什麼運動。所以做了這個「門診預約＋居家復健追蹤」串在一起的系統。

  • 一個人完成：訪談櫃檯人員與病患、人物誌、服務藍圖、B2B2C 訂閱制商業模式，到前後端開發與部署。
  • 病人點選身體不舒服的部位，系統推薦適合的治療師與時段；回家後有復健清單、疼痛紀錄與遵從率追蹤。
  • 前端 HTML/JS、Tailwind、Chart.js，後端用 Google Apps Script 串 Google Sheets，部署在 GitHub Pages。

關於我

「人生就像騎單車，想保持平衡就得往前走。」

我念運動醫學，學的是先找出問題根源，再給對方適合的方案。出社會後發現，比起直接服務一個人，我更喜歡在幕後把流程理順，讓整個現場跑得更順。

這幾年在櫃檯、門市和治療所之間，看過很多「大家都覺得麻煩，但沒人去改」的事。上了專案管理課程之後，我開始自己動手：訪談、畫流程、寫規格，再用 AI 工具把它做出來。

我希望下一份工作是產品營運、專案管理、服務設計或客戶成功，在第一線和開發團隊之間當那個把話講清楚的人。
